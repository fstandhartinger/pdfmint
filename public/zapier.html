PDFMint for Zapier

Turn HTML, Markdown, a URL or a saved template into a PDF inside a Zap, then hand the file straight to Gmail, Google Drive, Dropbox or the next step. The PDFMint integration is available as an opt-in private beta while it works toward Zapier’s public-directory usage requirement.

This is a private beta, not a public Zapier listing. The integration passes Zapier’s current structural and integration checks, but Zapier requires three users with live Zaps before an app can be submitted for public access. It currently has one. Joining is optional and creates no paid subscription; PDFMint’s free plan includes 10 documents a month and needs no card.

What the beta can do #

  • Generate PDF from HTML, Markdown or a URL.
  • Generate PDF from template by mapping fields from an earlier Zap step.
  • Generate image as PNG, JPEG or WebP.
  • Merge PDFs and return one file.
  • Save, find and list templates without copying template IDs by hand.

Generated files use Zapier’s normal file output, so the next step receives a file rather than a base64 string you have to decode.

Set it up #

  1. Create a free PDFMint account and copy the API key shown once.
  2. Accept the PDFMint 1.0.1 beta invitation on Zapier.
  3. Create a Zap, choose PDFMint, then paste the API key when Zapier asks for a connection.
  4. Run Zapier’s test step and inspect the returned PDF or image before turning the Zap on.

What we cannot claim yet #
